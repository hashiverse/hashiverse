## About

This library provides the rust/wasm backend for the associated hashiverse-client-web repo.

## Usage

[![test-hashiverse-client-wasm](https://github.com/hashiverse/hashiverse/actions/workflows/test-hashiverse-client-wasm.yml/badge.svg)](https://github.com/hashiverse/hashiverse/actions/workflows/test-hashiverse-client-wasm.yml) with `wasm-pack test --headless --chrome --lib`

## Get started

- Build for development with `wasm-pack build --dev`
- Build for release with `wasm-pack build --release`
- Run tests with `wasm-pack test --chrome --headless --lib`
